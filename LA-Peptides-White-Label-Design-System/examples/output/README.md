# Committed Example Output

These two folders are committed, pre-built samples — generated by `scripts/build.js` from the canonical sources at template v1.0.0 — so you can see finished output without installing Node or running a build:

- `la-peptides-default/` — built from `themes/la-peptides-default.theme.json` + `field-maps/la-peptides-default.field-map.json`
- `white-label-example-true-north/` — built from `themes/white-label-example-true-north.theme.json` + `field-maps/white-label-example-true-north.field-map.json`

They are **not hand-maintained**. If you change the canonical sources, regenerate them:

```bash
npm run build:default
npm run build:example
cp -r dist/la-peptides-default/* examples/output/la-peptides-default/
cp -r dist/white-label-example-true-north/* examples/output/white-label-example-true-north/
```

Everything your own builds produce under `dist/` is gitignored — only these example copies are tracked in git.
